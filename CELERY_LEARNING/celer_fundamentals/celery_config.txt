
A dedicated messaging system is a tool built only for sending, storing, 
and delivering messages (tasks) between different parts of a system.
RabbitMQ is a system whose ONLY job is to move tasks safely from one service to another.

📬 Receives a task (message)
🧾 Stores it in a queue
🚦 Keeps it safe until a worker is ready
📤 Sends it to Celery worker
✔ Confirms delivery (acknowledgment)


mean while 
Redis (NOT dedicated messaging system)
cache system first ⚡
can also act as a broker
multi-purpose tool

"""
CREATE FILE: config/celery.py
"""

from celery import Celery
import os

# Tell Celery where Django settings are
os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'config.settings')

# Create Celery instance
app = Celery('config')

# Load config from Django settings (CELERY_ prefix)
app.config_from_object('django.conf:settings', namespace='CELERY')

# Auto-discover tasks from all apps
app.autodiscover_tasks()


# Optional test task (for debugging)
@app.task(bind=True)
def debug_task(self):
    print(f"[CELERY DEBUG] Request: {self.request}")

"""
CREATE FILE: core/tasks.py

from celery import shared_task
import time

# Simple async task
@shared_task
def add(x, y):
    return x + y


# Example slow task (background processing)
@shared_task
def slow_task():
    time.sleep(10)
    return "Task completed after delay"
