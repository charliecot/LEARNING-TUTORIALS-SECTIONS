Welcome to Docker Compose

This page introduces Docker Compose, a tool for defining and running multi-container Docker applications. With Compose, you can describe your stack in a single docker-compose.yml file and manage it with simple commands.

Quick Start

Create a docker-compose.yml file in your project directory and define services, networks, and volumes. Then run docker compose up to start your application.

version: '3.9' services: web: image: nginx:latest ports: - "8080:80" app: build: . depends_on: - db db: image: postgres:15 environment: POSTGRES_USER: user POSTGRES_PASSWORD: secret POSTGRES_DB: appdb

Commands

Common Docker Compose commands:

  • docker compose up - Build, (re)create, start, and attach to containers for a service.
  • docker compose down - Stop and remove containers, networks, images, and volumes.
  • docker compose logs - View output from containers.

Use Docker Compose to simplify development workflows, orchestrate services, and keep your container configuration in one place.
